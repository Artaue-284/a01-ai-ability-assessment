- `synthetic_validation_100/`：100 份分层仿真样本、模拟双评、争议裁决和阈值校准；不得表述为真实学生或真实教师数据。
- `UI预览_*.png`：当前学生、教师、企业视角及移动端界面证据。

## 文档维护规则

1. 正式交付文档统一放在项目根目录的 `提交材料/`。
2. Word 渲染检查目录不进入 Git；需要时由生成脚本重新生成。
3. 同一内容只保留一个当前版本，历史版本由 Git 提交记录管理。
4. 文档中的“已实现”必须有代码、测试、接口或运行记录支撑。
5. 版本号、题库规模（301 题）与自动化测试数量（63 项）等口径须与代码保持一致，修改代码后同步更新相关文档。

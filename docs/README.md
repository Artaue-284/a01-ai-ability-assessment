# 文档索引

本目录只保留仍参与开发、验证或答辩的材料。已被正式 Word 文档取代的早期提纲和旧模拟报告，可通过 Git 首次基线提交 `874d587` 查阅。

## 当前有效文档

- `当前进度与后续任务复审.md`：已完成、部分完成和待办事项的证据边界。
- `部署与演示指南.md`：本地部署、局域网演示及访问控制。
- `题库建设规范.md`：六维度、题型、难度和审核要求。
- `测评有效性V2说明.md`：效度、信度与证据口径。
- `真实试测与评分验证方案.md`：未来真实学生和教师验证设计。
- `10人预测试执行包.md`：小规模真实预测试执行材料。

## 数据与界面证据

- `synthetic_validation_100/`：100份分层仿真样本、模拟双评、争议裁决和阈值校准；不得表述为真实学生或真实教师数据。
- `UI预览_*.png`：当前学生、教师、企业视角及移动端界面证据。

## 文档维护规则

1. 正式交付文档统一放在项目根目录的 `提交材料/`。
2. Word 渲染检查目录不进入 Git；需要时由生成脚本重新生成。
3. 同一内容只保留一个当前版本，历史版本由 Git 提交记录管理。
4. 文档中的“已实现”必须有代码、测试、接口或运行记录支撑。

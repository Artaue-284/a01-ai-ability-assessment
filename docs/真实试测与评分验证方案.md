# 真实试测与评分验证方案

## 样本建议

第一轮至少30名学员，尽量覆盖入门、基础、熟练和高级水平。若用于正式统计报告，建议继续扩大样本并记录年级、专业等必要但最小化的信息。

## 执行流程

1. 明确知情说明、数据用途和保存期限。
2. 学员完成25题深入测评。
3. 两名教师在不知道本地初评分数的条件下独立评阅开放题。
4. 分差达到满分20%时进入第三人裁决。
5. 导出作答与复核CSV，完成统计分析。

## 关键指标

- 完成率与平均完成时间。
- 每题曝光数、正确率、平均用时和高低分组区分度。
- 教师双评相关性与二次加权Kappa。
- 本地/模型初评与人工平均分的相关性。
- 测评等级与教师整体判断的一致率。
- 同一学员间隔一至两周复测的稳定性。

## 题目处理规则

- 曝光少于10次：只显示样本不足，不下质量结论。
- 正确率高于90%：检查是否过易或干扰项无效。
- 正确率低于20%：检查是否过难、表述歧义或教学范围不一致。
- 实测区分度低于0.15：优先复核能力归属、答案和干扰项。
- 出现多名学员反馈歧义：暂停题目并保留版本记录。

## 报告表述限制

合成用户模拟只能用于调试算法，不得表述为真实准确率。样本量不足30时，一致性指标只作为过程监测，不用于对外宣称评分有效性。

# 非百宝箱功能完成清单

## 学员端

- 15、18、25题三种测评题量。
- 分层随机与自适应补测，同场不重复。
- 客观题、开放作答与实操任务。
- 六维能力画像、维度分数、结果置信度和提升建议。
- 同一浏览器学员ID复用及历次测评成长档案。

## 教学管理端

- 管理员访问密钥保护。
- 参与人数、测评记录、完成记录和群体维度平均分。
- 题库新增、编辑、启用、停用、版本记录。
- 题库JSON批量导入和完整备份导出。
- 题目曝光次数、平均得分、平均用时、实测区分度和质量预警。
- 开放作答独立人工评分、双人评分展示和争议裁决。
- 模型—人工相关、评审间相关和加权Kappa过程指标。
- 作答明细与人工复核记录CSV导出。

## 本地评分与百宝箱边界

当前开放题使用透明的本地评分量表，仅作为离线演示初评，并统一进入人工复核队列。百宝箱尚未接入，系统状态接口明确返回 `baibaoxiang: pending`。获得接口和Token后，应在现有评分适配层增加百宝箱实现，并使用真实人工双评样本验证一致性。

## 尚需人工或外部资源完成

- 至少30名真实学员试测。
- 两名教师对开放题独立盲评。
- 根据真实数据校准难度、区分度、分数阈值和题目质量。
- 配置正式服务器、HTTPS、反向代理和备份策略。
- 接入百宝箱并验证其评分效果。
- 录制最终演示视频、完成提交平台操作。

# AI 能力测评智能体 · 全面功能测试流程

> 适用版本：v1.5.0（含平台三角色与企业闭环）
> 用途：验收测试方案 / 预测试执行清单 / 回归测试基线
> 测试方式：自动化（unittest 50 项）+ 手工功能验收（Web 界面）+ 线上冒烟

## 一、测试环境准备

### 1.1 本地启动
```powershell
python -m pip install -r backend/requirements.txt
python run.py                          # 浏览器打开 http://127.0.0.1:8000
python run.py --check                  # 仅校验应用可导入（OK: ... 1.5.0）
```
- 访问 `http://127.0.0.1:8000/api/status` 应返回 `status=ok`、`version=1.5.0`、`question_bank.total=300`、`assessment_readiness.ready=true`。
- 访问 `http://127.0.0.1:8000/docs` 应能看到全部 API 文档。

### 1.2 密钥与账号准备
| 凭据 | 来源 | 用途 |
|---|---|---|
| 管理密钥 | `data/admin_key.txt`（首次启动自动生成） | 教学管理入口、创建账号 |
| 企业密钥 | `data/enterprise_key.txt` | 企业工作台密钥登录 |
| 教师账号 | 教学管理 → 账号管理创建（如 `teacher01/demo123`） | [06] 登录 |
| 企业账号 | 教学管理 → 账号管理创建（如 `company01/demo123`） | [06] 登录 |
| ant-line 密钥 | `data/llm_config.json`（可选手动删除以测降级） | 评分/AI 助手真实模型 |

> 注意：`llm_config.json` 含真实密钥，正式提交前删除；admin/enterprise 密钥勿发给测试者。

### 1.3 演示数据（可选）
```powershell
python tools/create_demo_data.py --users 12   # 生成 12 名演示学员及测评记录
```

### 1.4 自动化测试基线
```powershell
python -m unittest discover -s tests -v       # 期望：Ran 38 tests, OK
```
覆盖：题库结构/均衡、自适应引擎、评分（百宝箱/ant-line/规则降级）、AI 助手、对话/证据、
选项顺序回归、企业匹配、**三角色权限与企业投递闭环**。

> 每条用例：前置 → 步骤 → 预期。标记 [A] 自动化已覆盖、[M] 需手工执行。

### 模块 1：系统基础与题库

| 用例 | 类型 | 步骤 | 预期 |

| TC-01-01 服务启动 | [M] | 双击 `一键启动.bat` 或 `python run.py` | 控制台列出本机/局域网地址，浏览器自动打开首页 |

| TC-01-03 题库校验 | [A] | `GET /api/question-bank/stats`（管理密钥） | valid=true；6 维每维≥15；题型含 single_choice/open_text/practical/dialogue/code/image；无重复 ID |

### 模块 2：学员端测评流程

| 用例 | 类型 | 步骤 | 预期 |
|---|---|---|---|
| TC-02-01 开始测评 | [M] | 填姓名/代号+班级，选 15/18/25 题，勾选同意 → 领取测评 | 进入第 1 题（客观题）；题号 1-12 可自由选择，13 起锁定 |
| TC-02-02 客观题作答 | [M] | 选择答案 → 提交 | 即时判定（正确/部分/错误）；显示参考答案与解析 |
| TC-02-03 选项顺序一致性（回归） | [A] | 提交后回看已答客观题 | 选项内容与位置和作答时完全一致（不因题库原始顺序错位） |
| TC-02-04 题号导航 | [M] | 在 1-12 内乱序点题号答题 | 阶段内自由切换；已答题目显示对/半对/错状态；完成 12 题后解锁自适应题组 |
| TC-02-05 开放作答题（纯文本提交） | [M] | 进入 open_text 题 → 文本框输入答案 → 提交 | 页面无"上传证据"文件入口；答案文本提交成功并显示得分与评分要点 |
| TC-02-06 结构化引导 | [M] | 开放题点击"请求引导"（最多6轮） | 返回不代答的引导文案；对话记录展示 |
| TC-02-07 AI 助手对话 | [M] | 主观题【AI 助手】发送消息（最多12轮/题） | 有配置时返回真实模型回复（气泡标注模型名）；未配置显示"本地模拟助手"；失败显示降级警告 |
| TC-02-08 对话式任务（新题型） | [M] | 完成 dialogue 题：至少3轮有效对话后提交总结 | 题干提示使用【AI 助手】；提交后得分正常，对话记录作为评分证据 |
| TC-02-09 代码任务（新题型） | [M] | code 题：等宽代码框输入代码+核验方法 → 提交 | 代码框等宽显示；提交后显示评分要点 |
| TC-02-10 图像鉴别（新题型） | [M] | image 题：观察内置图，判断是否 AI 生成并写依据 | 图片正常显示；提交后按量表评分 |
| TC-02-11 中断续答 | [M] | 答题中途刷新页面 | 首页出现"继续上次测评"；点击可恢复进度与已答状态 |
| TC-02-12 防泄题 | [M] | 查看已提交客观题解析后再作答 | 已提交题目只读；未提交题目不泄露答案 |
| TC-02-13 完成测评 | [M] | 答完所有题目（含 open+practical+dialogue） | 提示全部完成 → 进入报告 |

## 三、回归冒烟清单（每次改动后必跑）

```powershell
python -m unittest discover -s tests -v        # 50 项全绿
node --check 前端脚本段                          # JS 语法
python run.py --check                           # 应用导入
```
手工冒烟（5 分钟）：开始测评 → 答 2 道客观题（验证顺序一致）→ 开放题用 AI 助手对话后提交 → 完成报告（雷达图+训练资源）→ 岗位广场投递 → 教学管理数据概览（投递统计）→ 企业工作台查看投递。

## 四、线上部署验证

1. 双击 `一键启动.bat` 后运行 `启动远程测试.bat`；
2. 打开输出的 `https://*.trycloudflare.com`：首页 200、/api/status ok；
3. 请同学访问同一地址完成一次完整测评；
4. 验证 ant-line 评分真实返回（或提示降级原因）；
5. 用后关闭窗口（隧道失效），确认 `data/remote_test_url.txt` 更新。

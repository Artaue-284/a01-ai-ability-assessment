# 使用说明与后续任务

> 适用版本：AI 能力测评智能体 v1.5.0

## 一、快速启动

### 1.1 环境要求
- Windows / macOS / Linux
- Python 3.10 及以上

### 1.2 启动步骤

```powershell
# ① 安装依赖（首次）
python -m pip install -r backend/requirements.txt

# ② 启动服务
python run.py
```

或直接双击 `一键启动.bat`。启动后浏览器会自动打开 `http://127.0.0.1:8000`；
同一局域网队友访问 `http://本机局域网IP:8000`（保持启动窗口开启）。

### 1.3 可选：接入真实 AI 环境（评分 + 对话助手）

**方式 A：百宝箱评分/对话智能体**（推荐，赛题对接真实 AI 环境）

```powershell
$env:TBOX_TOKEN="你的评分智能体令牌"
$env:TBOX_APP_ID="202608AP95fB21469777"   # 或你的对话智能体 APP ID
python run.py
```

**方式 B：OpenAI 兼容接口**

```powershell
$env:OPENAI_API_KEY="你的密钥"
$env:OPENAI_MODEL="模型名称"
# 可选：$env:OPENAI_BASE_URL="兼容服务地址"
python run.py
```

配置后 `GET /api/status` 会显示：
- `scoring_mode=baibaoxiang-agent` / `responses-api`（开放题自动评分）
- `ai_assistant_mode=baibaoxiang-agent` / `responses-api`（测评中 AI 助手返回真实模型回复）

未配置时自动降级：
- 评分 → `local-rubric` 透明规则评分，并标记“需要人工复核”
- AI 助手 → `local-simulator` 本地模拟助手，界面会明确标注“本地模拟”，不会冒充真实模型

### 1.4 教学管理密钥
首次启动自动生成在 `data/admin_key.txt`（仅项目负责人本机查看），企业协作密钥在 `data/enterprise_key.txt`。
也可以通过环境变量覆盖：`$env:A01_ADMIN_KEY="自定义密钥"`。

## 二、功能使用说明

### 2.1 学员端（开始测评）
1. 首页填写“姓名或测试代号”（可匿名）+ 班级/团队（选填）。
2. 选择测评题量：快速 15 / 标准 18 / 深入 25（队内预测试推荐 25）。
3. 勾选数据说明同意后“领取测评”。
4. 前 12 题按六维分层随机；完成初测后解锁自适应题组与主观题。

**三种测评玩法（本次补全）：**
- **[A] 客观题**：选择题，提交后即时判定与解析。
- **[B] 对话式（新增题型）**：题目描述一个任务场景，学员在题目下方的【AI 助手】中与 AI 协作（提问→获取建议→追问细节，建议至少 3 轮），再把任务结论整理成最终答案提交。AI 助手对话记录会作为本题评分证据。
- **[C] 实操/代码/图像任务**：
  - 实操任务：按题目要求给出执行方案，直接在文本框中提交文字答案（纯文本提交，无需上传文件）。
  - 代码任务（新增）：在等宽代码框中编写代码并说明核验方法；可先向 AI 助手咨询实现思路。
  - 图像鉴别（新增）：观察题目内置的 AI 生成风格图片（含典型破绽：六指、悬空窗、光影矛盾），判断是否 AI 生成并给出依据。

**AI 助手使用要点：**
- 每道主观题最多 12 轮对话，每次测评总计不超过 80 条记录。
- 发送区会显示当前模式：真实模型 / 本地模拟助手。
- 对话内容连同最终答案一起参与自动评分（人机协同维度）。

### 2.2 报告与成长档案
- 提交完成后生成个人能力报告：综合分与 L1~L5 等级、六维雷达图、维度置信度、错题/主观题解析、薄弱项建议、**训练资源推荐（新增）**、岗位能力参考（需主动授权）。
- 首页 [02] 成长档案：查看本浏览器关联学员的历次测评得分。

### 2.3 教师端（教学管理）
在首页导航进入 [04] 教学管理，输入管理密钥：
- **数据概览**：参与人数、测评数、维度平均分、最近完成记录。
- **题库管理**：新增/编辑/启停题目（支持客观题、开放作答、实操任务、**对话任务、代码任务、图像鉴别**及图片资源地址），查看作答统计（曝光、均分、区分度）与版本记录，批量 JSON 导入导出。
- **人工复核**：开放/实操/对话/代码/图像题的双人评分、争议裁决与一致性指标（Pearson、加权 Kappa）。
- **成长追踪（新增）**：选择学员后展示其历次测评的综合分与六维得分折线图，用于追踪能力成长曲线。
- **预测试反馈**：查看体验评分、歧义题、操作问题。
- **数据导出**：作答明细/反馈/复核记录 CSV + 题库 JSON 备份。

### 2.4 企业端（企业协作）
首页导航进入 [05] 企业协作，输入企业密钥：
- 查看匿名群体能力画像（样本不足阈值时不展示，防止身份推断）。
- 管理岗位能力模板（AI 应用助理、提示词运营、AI 项目协调）的启停。
- 学员主动授权后可查看个人岗位能力参考（企业端不可见个人数据）。

### 2.5 平台三角色与企业闭环（校企轻量化业务）
导航栏 [06] 登录支持教师/企业账号，学员无需登录（沿用测评时生成的本地身份）。

**账号管理（管理员）**：教学管理 → 账号管理，创建教师/企业登录账号（用户名、显示名称、机构/班级、初始密码），可启停账号、重置密码。

**教师 / 培训师**：登录后直接进入教学管理（等同管理员），并可在教师工作台查看班级投递统计（按岗位、按班级）。

**企业 / 用人单位**：登录后进入企业工作台：
- 发布岗位：填写岗位名称/描述，选择关联的能力模板（AI 应用助理 / 提示词运营 / AI 项目协调）→ 学员端可见；
- 启停岗位：关闭后停止接收投递，学员端岗位广场不再显示；
- 查看投递：显示投递学员的姓名、班级、联系方式与匹配分（学员自愿授权共享能力画像摘要，不接触原始答案与个人报告）。

**学员**：测评完成后在报告页【岗位广场】：
- 浏览企业发布的开放岗位（含匹配模板说明与已投递人数）；
- 勾选"同意企业查看我的能力画像摘要"、填写联系方式（选填）→ 授权并投递；
- 每个岗位限投一次；投递记录可追溯，企业端不得用于自动录用或淘汰。

**权限边界**：教师令牌仅能访问教学管理；企业令牌仅能访问企业工作台；无效/过期令牌返回 401，跨角色访问返回 403。

## 三、后续任务（按优先级）

### P0 提交前必做
1. **真实评分验证**：配置百宝箱/大模型密钥，组织 10~30 名学员完成真实测评；邀请 2 名教师对主观题（含新增的对话/代码/图像题）独立双评；在“人工复核”页计算模型—人工 Pearson 与加权 Kappa，用真实数据支撑“自动评分准确性”评分项。
2. **稳定在线环境**：把服务部署到固定域名/服务器（或录制 7~9 分钟演示视频），替代 Cloudflare Quick Tunnel 临时地址。
3. **参赛通用材料**：S1 方案概要、S2 解决方案（含角色分工）、S3 答辩 PPT、团队过程材料、原创承诺书；文件名与内容全程匿名（不出现学校/教师信息）。

### P1 质量打磨
4. 用真实图片替换程序化 SVG 图像素材，扩充图像鉴别题（建议真实 AI 生成图 vs 真实照片对比集）。
5. 代码任务接入受限执行沙箱（如受限 Docker 或在线判题 API），实现“运行并核验”而不是仅按量表评分。
6. 依据预测试反馈修订题干（历史遗留：BA203、CO203、ET204 短题干复核）；统一 README 与 API 版本号。

### P2 竞争力增强
7. 对话式测评增加难度梯度（多轮复杂任务、角色扮演、故障排查场景），并把对话轮次、提问质量纳入自适应路由。
8. 题库按“维度 × 题型 × 难度 × 标签”扩充到千题（新增题目必须经教师审核难度与区分度）。
9. 能力画像接入课程设置/技能认证场景：班级课程推荐、LMS/证书接口原型、多租户与统一身份。

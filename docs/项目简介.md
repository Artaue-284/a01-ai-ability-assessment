# AI 能力测评智能体 · 项目简介（v1.5.0）

## 一、一句话定位

面向 A01 赛题/教学场景的**六维 AI 能力测评智能体**：自适应出题 → 三种测评模式 → 自动评分（真实大模型）→ 能力报告与成长追踪 → **平台三角色权限 + 企业轻量化校企闭环**，可本地运行、可一键上线分享。

## 二、核心能力

### 1. 六维能力模型（L1~L5 可观察行为标准）
AI 基础认知 · 提示词工程 · AI 工具使用 · 结果评估与优化 · 人机协同 · 伦理与合规

### 2. 三种测评模式
- **客观题**：84 道选择题，自适应难度，即时判定+解析，选项顺序与提交视图一致（已修复回归）
- **对话式**（新增题型）：与【AI 助手】多轮协作完成任务后提交总结，对话记录计入评分
- **实操/代码/图像**（新增）：实操方案、代码编写与核验、AI 生成图像鉴别（内置破绽图）

### 3. 六大技术点
| 技术点 | 实现 |
|---|---|
| 大模型判题 | 百宝箱 → ant-line（蚂蚁百灵）→ OpenAI 兼容 → 规则降级，JSON 校验+分数钳制+置信度强制复核，对话上下文参与人机协同评分 |
| 自适应出题 | 分层随机初测 + 置信度/薄弱维度补测 + 提前停止，15/18/25 题三档 |
| 多模态 | 文本、代码（等宽编辑）、图像鉴别（SVG 破绽图）、过程证据（对话/AI 助手） |
| 数据可视化 | 六维雷达图、成长曲线折线图、班级看板、匿名群体画像、训练资源推荐 |
| 对接真实 AI 环境 | 测评内【AI 助手】真实调用蚂蚁百灵 Ling-3.0-flash；未配置透明降级并标注 |
| 题库管理后台 | 增/改/启停/版本追溯/批量导入导出，支持全部 6 种题型 |

### 4. 平台三角色与企业闭环
- **三角色权限**：教师/企业账号（PBKDF2 口令哈希 + 7 天会话令牌），学员沿用本地身份；接口按角色鉴权（跨角色 403、无效 401）
- **企业轻量化闭环**：企业发布岗位（关联能力模板）→ 学员报告页【岗位广场】授权投递 → 企业查看脱敏申请（姓名/班级/联系方式/匹配分）→ 关闭岗位 → 教师查看班级投递统计

## 三、技术架构

| 层 | 技术 | 说明 |
|---|---|---|
| 后端 | Python 3.10+ / FastAPI / Uvicorn | REST API + 静态托管，零第三方重量依赖 |
| 数据库 | SQLite（data/assessment.db） | 用户/测评/答案/题库/复核/反馈/账号/会话/岗位/投递 |
| 算法 | 自适应测评引擎 + 模拟验证 | 得分平滑、置信度计算、分类准确率模拟 |
| 前端 | 单文件 HTML/CSS/JS（零依赖离线可运行） | 原生 Canvas 图表，移动端适配 |
| 模型 | 蚂蚁百灵 ant-ling（OpenAI 兼容）/ 百宝箱 / OpenAI / 本地规则 | 评分与 AI 助手双通道，多级降级 |
| 部署 | 一键启动 BAT + Cloudflare Quick Tunnel | 局域网/公网临时分享；可迁移国内云服务器 |

## 六、使用路径（30 秒上手）
1. `python -m pip install -r backend/requirements.txt && python run.py`
2. 学员：首页开始测评 → 报告（雷达图/训练资源/岗位广场投递）
3. 教师：[06] 登录 → 教学管理（看板/题库/复核/成长/账号）
4. 企业：[06] 登录 → 发布岗位 → 查看投递
5. 分享：`启动远程测试.bat` → 发 trycloudflare 地址给同学

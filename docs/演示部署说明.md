# A01 演示部署说明

## Render 设置

1. 将项目上传到 GitHub 私有或公开仓库。
2. 在 Render 中创建 `Web Service`，选择该仓库。
3. 选择 Docker Runtime；也可以让 Render 自动读取根目录的 `Dockerfile`。
4. 健康检查路径填写 `/api/status`。
5. 设置以下环境变量：

   - `A01_ADMIN_KEY`：长度至少 24 位的演示管理员密钥。
   - `A01_ENTERPRISE_KEY`：长度至少 24 位的演示企业密钥。
   - `A01_REQUIRE_ENV_SECRETS=1`：禁止服务在云端自动落盘生成密钥。
   - `A01_PUBLIC_MODE=1`：启用公网安全响应头。
   - `A01_ALLOWED_HOSTS`：填写 Render 域名，例如 `a01-ai-ability-assessment-demo.onrender.com`。
   - `A01_CORS_ORIGINS`：如果前端与 API 同域可留空；跨域时只填写明确的前端域名，禁止使用 `*`。
   - `TBOX_TOKEN`、`TBOX_APP_ID`：只有需要真实百宝箱评分/对话时才配置。
   - `ANT_LINE_API_KEY` 等 ant-line 变量：只有需要真实 ant-line 通道时才配置。

## 演示注意事项

- 本演示使用 SQLite，Render 实例重建后数据可能丢失；不要把它当作正式数据存储。
- 演示数据库首次启动为空，需要先用管理员密钥创建教师/企业账号，或导入演示数据。
- 不要上传 `data/assessment.db`、`data/*_key.txt` 或 `data/llm_config.json`。
- 如果 `data/llm_config.json` 中的 Token 曾经提交到任何公开仓库，应立即在模型平台撤销并重新生成。
- 部署完成后访问 `https://你的服务名.onrender.com/api/status`，确认返回 `status=ok`。
- 使用两个教师账号对同一批开放题进行独立评分，再用第三个教师账号进行争议裁决。

# AI能力测评智能体功能设计

## 产品定位

面向高校学员、教师和培训管理者，通过客观题、开放作答与实操任务，对AI基础认知、提示词工程、AI工具使用、结果评估与优化、人机协同、伦理与合规六个维度进行量化评估。

## 用户角色

- 学员：创建测评、完成自适应题目、查看能力报告和历次成长档案。
- 教师/评审：查看群体画像、复核开放作答、分析题目质量。
- 题库管理员：新增、编辑、启停、批量导入、备份题目并追踪版本。

## 核心流程

学员填写基本信息 → 创建独立测评 → 六维分层随机初测 → 向薄弱或低置信度维度补测 → 开放作答与实操任务 → 本地评分量表初评 → 六维能力报告 → 教师双人复核 → 分歧裁决与测评校准。

## 学员端功能

- 15题快速、18题标准和25题深入三种题量。
- 同一测评题目不重复，六个维度均得到覆盖。
- 选择题、开放作答与实操任务使用对应交互组件。
- 报告展示综合得分、L1～L5等级、六维雷达图、维度置信度和提升建议。
- 浏览器保存随机学员ID，用于关联历次完成记录，不保存密码。

## 教学管理功能

- 群体参与人数、测评数、完成数及六维平均分。
- 题库按ID、题干、标签检索；支持编辑、启用、停用和版本追踪。
- 题目统计包含曝光次数、平均得分、平均用时、实测区分度和质量预警。
- 开放答案支持两名评审独立评分，并对分歧给出最终裁决。
- 过程指标包含模型—人工相关、评审间相关和二次加权Kappa。
- 支持题库JSON备份/导入、作答明细和人工复核CSV导出。

## 当前评分边界

百宝箱尚未接入。开放作答当前由透明的本地评分量表进行初评，并标记为需要人工复核。本地初评分数不能替代正式人工结论，也不能用于宣称大模型评分准确性。

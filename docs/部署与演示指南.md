# 部署与演示指南

## 本地启动

双击 `一键启动.bat`，或执行：

```powershell
E:\Anaconda\python.exe run.py
```

访问 `http://127.0.0.1:8000`。教学管理本地默认密钥为 `a01-local-admin`。

## 演示前准备

1. 设置自定义 `A01_ADMIN_KEY`。
2. 备份或替换 `data/assessment.db`。
3. 如需看板数据，运行 `python tools/create_demo_data.py --users 12`。
4. 检查 `/api/status` 返回题库90题、状态ok、百宝箱pending。
5. 使用无痕窗口走一遍18题完整测评。

## 建议演示脚本

1. 首页介绍六维能力模型与三阶段测评方法。
2. 创建18题标准测评，展示随机客观题、自适应难度和开放任务。
3. 展示六维雷达图、置信度和提升建议。
4. 打开成长档案查看历次结果。
5. 登录教学管理，展示群体画像、题目统计和质量预警。
6. 对同一开放答案进行两次独立评分并展示一致性指标。
7. 展示题目编辑、版本、启停和CSV/JSON导出。
8. 明确百宝箱为待接入项，说明接入后替换评分适配层。

## 正式部署待办

当前为本地比赛原型，不应直接暴露到公网。上线前必须配置反向代理、HTTPS、正式登录鉴权、PostgreSQL、自动备份、日志轮转和隐私政策。

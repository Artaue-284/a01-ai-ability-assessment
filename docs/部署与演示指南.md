# 部署与演示指南

## 本地启动

双击 `一键启动.bat`，或执行：

```powershell
E:\Anaconda\python.exe run.py
```

访问 `http://127.0.0.1:8000`。教学管理密钥首次启动时自动生成于 `data/admin_key.txt`，也可用环境变量 `A01_ADMIN_KEY` 覆盖。

> `127.0.0.1` 只能在本机打开，不是公网地址。

## 临时公网演示（异地访问）

这是当前比赛演示推荐流程：

1. 双击 `一键启动.bat`，等待浏览器中的本地首页正常打开。
2. 双击 `启动远程测试.bat`。
3. 等待窗口出现 `Your quick Tunnel has been created`。
4. 复制窗口中完整的 `https://随机名称.trycloudflare.com` 地址发给异地测试者。
5. 不要发送 `http://127.0.0.1:8000` 或 `http://192.168...:8000`，它们分别只供本机或同一局域网使用。
6. 网站窗口与隧道窗口必须同时保持运行；电脑不能关机、休眠或断网。

Quick Tunnel 的公网域名每次启动通常都会改变。如果隧道窗口提示网站仍使用旧 Host 白名单，请关闭旧的网站启动窗口，重新双击 `一键启动.bat`，然后再次运行 `启动远程测试.bat`。

公网验证方式：使用手机关闭 Wi-Fi、切换到移动数据，然后打开该 `https://...trycloudflare.com` 地址；能够加载首页且 `/api/status` 返回 `status: ok` 才表示真正公网可访问。

## 演示前准备

1. 设置自定义 `A01_ADMIN_KEY`。
2. 备份或替换 `data/assessment.db`。
3. 如需看板数据，运行 `python tools/create_demo_data.py --users 12`。
4. 检查 `/api/status` 返回题库301题、状态ok；`scoring_mode` 按配置显示（ant-line-api / baibaoxiang-agent / local-rubric）。
5. 使用无痕窗口走一遍18题完整测评。

## 建议演示脚本

1. 首页介绍六维能力模型与三阶段测评方法。
2. 创建18题标准测评，展示随机客观题、自适应难度和开放任务。
3. 展示六维雷达图、置信度和提升建议。
4. 打开成长档案查看历次结果。
5. 登录教学管理，展示群体画像、题目统计和质量预警。
6. 对同一开放答案进行两次独立评分并展示一致性指标。
7. 展示题目编辑、版本、启停和CSV/JSON导出。
8. 说明评分模式：已接入 ant-line 真实模型评分与 AI 助手；百宝箱评分智能体已发布，配置令牌后启用，未配置时透明降级并显式标注。

## 长期云端部署待办

Quick Tunnel 仅用于临时比赛演示，不是持续在线的云服务器。长期上线仍需配置固定域名、正式登录鉴权、PostgreSQL、自动备份、日志轮转和隐私政策。

# 未来发展与生态整合

## 产品迭代

- 使用真实学员数据校准题目难度、区分度和等级阈值。
- 增加代码、图像辨识等可验证的多模态任务。
- 建立岗位能力模板、课程目标模板和证书标准。
- 将薄弱维度映射到学习资源，形成“测评—学习—练习—复测”闭环。

## 教育生态整合

- 通过标准API与学校统一身份、课程平台和学习档案对接。
- 向教师提供班级共性短板与课程内容调整建议。
- 向学员提供阶段目标、训练任务和成长曲线。
- 仅在获得明确授权后，将能力画像用于岗位匹配或技能认证，并提供人工复核与申诉。

## 市场推广

- 先在单门AI通识课程开展小规模试点。
- 用真实一致性、完成时间和教师工作量数据证明价值。
- 形成高校版、企业培训版和个人学习版，能力标准保持一致，题目场景按行业配置。

## 技术演进

- SQLite迁移PostgreSQL，支持机构、班级、角色和多租户隔离。
- 基于真实响应数据估计IRT参数并优化停止规则。
- 接入百宝箱评分与对话能力，同时保留规则校验、人工复核和失败降级。
- 建立模型、提示词、题库和评分量表的联合版本管理。

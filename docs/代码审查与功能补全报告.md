## 五、仍然存在的差距（非本次范围）

1. **评分真实性证据**：当前评分模式为 `local-rubric`（未配置百宝箱/大模型密钥），模型—人工一致性（Pearson、加权 Kappa）仍无真实数据，需要真实学员试测+教师双评。
2. **代码沙箱**：代码任务按评分量表评分，未做真实代码执行沙箱（建议后续接入受限执行环境或 API 判题）。
3. **图像任务素材**：当前为程序化 SVG 示例；正式使用建议替换为真实 AI 生成图/真实照片对比集。
4. **稳定在线环境**：Cloudflare Quick Tunnel 仅适合临时预测试，正式提交需要固定域名/服务器。

# A01 题库建设规范

## 最低题量

每个能力维度至少15题：10道基础/进阶客观题、3道高阶客观题、1道开放题、1道实操或场景任务。当前第一版按“13道新客观题 + 1道既有高阶题 + 1道开放/实操题”组成每维15题。

## 难度定义

- 难度1：概念识别和单一步骤判断，对应L1～L2。
- 难度2：情境应用、比较与简单任务拆解，对应L2～L3。
- 难度3：复杂约束、流程设计、评测和治理，对应L3～L4。
- L5不通过单道选择题判定，必须结合开放/实操表现及多次测评证据。

## 质量门槛

每题必须具备唯一ID、能力维度、难度、题型、标签、题干、有效选项、唯一最佳答案和解释。错误选项应对应真实常见误区，不能只使用明显荒谬的干扰项。

不得仅通过改写措辞制造重复题。涉及具体模型版本、法律条文或产品功能的题目应标记复核日期，避免内容过时。

## 审核流程

1. 编写者完成题干、答案、解释和能力标签。
2. 第二名成员盲答并检查歧义。
3. 教师或领域人员复核难度与能力归属。
4. 小样本试测后统计正确率和选项分布。
5. 根据区分度保留、修改或停用题目。

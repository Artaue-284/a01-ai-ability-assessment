# AI 能力测评智能体 v1.5

面向 A01 赛题的可运行版本，已实现：

- 六维 AI 能力模型与 300 题题库（每维 50 题：客观 30 + 开放/实操各 4 + 对话/代码/图像/判断各 3）
- 三种测评模式：客观题、对话式任务（新增）、实操/代码/图像任务（新增）
- 按“维度 × 题型 × 难度”分层随机抽题，同场不重复
- 根据得分、题量、用时与置信度进行自适应补测
- 15～25 题测评与提前停止机制
- SQLite 用户、测评和答题记录，多用户会话互不干扰
- 客观题规则评分、开放题结构化评分、可选真实 LLM 接入
- **AI 助手（对接真实 AI 环境）**：测评中可直接与 AI 对话完成任务，对话记录计入评分证据；未配置模型时透明降级为本地模拟助手
- 六维雷达图、证据记录、薄弱项建议、**训练资源推荐**与教师班级看板
- **平台三角色权限**：教师/企业账号登录（PBKDF2 口令哈希 + 会话令牌），学员沿用本地身份；接口按角色鉴权
- **企业轻量化业务闭环**：企业发布岗位（关联能力模板）→ 学员报告页【岗位广场】授权投递 → 企业查看匹配申请 → 教师查看班级投递统计
- 六维 L1～L5 可观察行为标准及网页说明
- 题库管理、启停状态、版本记录与批量导入导出（支持对话/代码/图像新题型）
- 开放作答双人复核、争议裁决与一致性指标
- 学员成长档案、**教师成长追踪曲线（新增）**、题目质量统计和研究数据CSV导出
- 预测试知情说明、中断续答、过程防泄题和测试反馈闭环
- 分阶段题号导航：阶段内自由选题，完成初测后解锁自适应题组

## 启动

需要 Python 3.10 或更高版本：

```powershell
python -m pip install -r backend/requirements.txt
python run.py
```

或双击 `一键启动.bat`。启动窗口会列出：

- `http://127.0.0.1:8000`：项目负责人在本机访问。
- `http://本机局域网IP:8000`：同一 Wi-Fi 或局域网内的队友访问。

队友测试期间必须保持启动窗口开启。如果队友无法访问，请确认双方在同一网络，并允许 Python 通过 Windows 防火墙的“专用网络”。不要把教学管理密钥发给普通测试者。

远程队友不在同一网络时：先运行 `一键启动.bat`，再运行 `启动远程测试.bat`，将窗口中生成的 `https://*.trycloudflare.com` 地址发给队友。该地址仅适合临时预测试，任一窗口关闭后即失效，并且下次启动通常会变化。

队内预测试建议选择 25 题模式。系统支持刷新后继续未完成测评；测试结束后，队友可以在报告页提交体验评分、歧义题、操作问题和报告反馈。

首次启动时会在 `data/admin_key.txt` 自动生成教学管理密钥。该文件仅供项目负责人本机查看，不要发送给普通测试者。也可以通过环境变量覆盖：

```powershell
$env:A01_ADMIN_KEY="自定义高强度密钥"
python run.py
```

## 平台三角色与企业闭环

导航栏 [06] 登录支持**教师/企业账号**（学员无需登录，沿用测评时生成的本地身份）。账号由管理员在教学管理 → 账号管理中创建：

- **教师 / 培训师**：登录后进入教学管理（等同管理员权限），可查看班级看板、题库、人工复核、成长追踪与账号管理；教师工作台另有班级投递统计。
- **企业 / 用人单位**：登录后进入企业工作台，可查看匿名群体画像、启停岗位模板、**发布岗位**、查看学员投递（脱敏：姓名/班级/联系方式/匹配分，不接触原始答案与个人报告）。
- **学员**：测评完成后在报告页【岗位广场】浏览开放岗位，勾选授权（共享六维能力画像摘要）后投递；每岗位限投一次，企业端不得用于自动录用或淘汰。

闭环流程：企业发布岗位（关联能力模板）→ 学员测评后授权投递 → 企业查看匹配申请并可关闭岗位 → 教师查看班级投递统计。令牌有效期 7 天，口令以 PBKDF2 哈希存储。

## 百宝箱评分智能体

已发布的评分智能体 APP ID 为 `202608AP95fB21469777`。启动前在当前 PowerShell
会话中配置令牌和 APP ID；令牌只保存在进程环境变量中，不要写入代码、截图或题库：

```powershell
$env:TBOX_TOKEN="你的评分智能体令牌"
$env:TBOX_APP_ID="202608AP95fB21469777"
python run.py
```

系统会调用 `POST https://api.tbox.cn/api/chat`，校验百宝箱返回的结构化评分 JSON，
并把分数限制在题目满分范围内。远程调用异常时会显式标注警告并降级为
`rubric-fallback-v1`，不会把降级结果冒充为真实模型评分。

`GET /api/status` 中：

- `scoring_mode=baibaoxiang-agent` 表示百宝箱配置已加载；
- `baibaoxiang=configured` 表示令牌和 APP ID 均已配置；
- `scoring_mode=ant-line-api` 表示 ant-line 通道已加载（见上文接入说明）；
- `scoring_mode=local-rubric` 表示当前仍是离线规则评分。

## AI 助手（对接真实 AI 环境）

测评中的对话式任务、代码任务、图像鉴别等主观题下方提供【AI 助手】对话窗口。
配置百宝箱、ant-line 或 OpenAI 兼容接口后，助手返回真实模型回复；未配置时降级为
`local-simulator` 本地模拟助手，并在界面明确标注“本地模拟”。

- 每道主观题最多 12 轮对话，每次测评总计不超过 80 条记录。
- 对话记录随最终答案一起参与评分（人机协同维度），教学管理中可追溯。

## ant-line（蚂蚁百灵 Ant-Ling）接入

ant-line 通道使用 OpenAI 兼容的 `/chat/completions` 端点，用于开放题评分和 AI 助手对话。
已在本项目 `data/llm_config.json` 中写入配置（该文件含真实密钥，**提交/打包材料前请删除**，
也不要发送给普通测试者）：

```json
{
  "api_key": "sk-studio-...",
  "base_url": "https://api.ant-ling.com/v1",
  "model": "Ling-3.0-flash"
}
```

可用模型（`GET https://api.ant-ling.com/v1/models` 可实时查询）：

- 通用对话/评分：`Ling-3.0-flash`（默认，速度较快）、`Ling-3.0-tiny`、`Ling-2.6-1T`、`Ling-2.5-1T`
- 推理与代码（评分更严谨）：`Ring-2.6-1T`、`Ring-2.5-1T`

也可以不落盘，改用环境变量（优先级高于配置文件）：

```powershell
$env:ANT_LINE_API_KEY="你的密钥"
$env:ANT_LINE_BASE_URL="https://api.ant-ling.com/v1"
$env:ANT_LINE_MODEL="Ling-3.0-flash"
python run.py
```

`GET /api/status` 中 `ant_line=configured` 表示已加载，`scoring_mode=ant-line-api`、
`ai_assistant_mode=ant-line-api` 表示评分与对话均走 ant-line；调用失败时自动降级并
显式标注警告（含 HTTP 状态码与原因），不会冒充真实模型。

## 其他兼容大模型评分

未配置密钥时，开放题使用透明的 `rubric-fallback-v1` 规则评分，并标记需要人工复核。配置以下环境变量后会调用兼容 Responses API 的服务：

```powershell
$env:OPENAI_API_KEY="你的密钥"
$env:OPENAI_MODEL="模型名称"
python run.py
```

也可以通过 `OPENAI_BASE_URL` 指向兼容服务。密钥不会写入代码或数据库。

## 千题题库设计

系统不限制题库规模。每题使用统一字段：

```json
{
  "id": "PR1001",
  "dimension": "prompt",
  "difficulty": 2,
  "type": "single_choice",
  "tags": ["上下文", "少样本"],
  "question": "题干",
  "options": ["A", "B", "C", "D"],
  "answer": "A",
  "max_score": 10
}
```

主观题可扩展为 `open_text`（开放作答）、`practical`（实操任务）、`dialogue`（对话任务）、
`code`（代码任务）、`image`（图像鉴别，需 `image_url` 图片资源地址）。

扩展到千题时应由教师或领域专家审核题目质量、答案、难度和区分度，不建议用模板机械复制。抽题流程是：

1. 前 12 题按六维和基础/进阶难度配额分层随机；
2. 中段向低置信度或薄弱维度动态补题；
3. 末段加入开放题、实操任务与对话式任务（题库含代码/图像题时自动纳入）；
4. 同一测评根据题目 ID 去重；
5. 达到目标题量，或满足提前停止条件后生成报告。

当前题库为 300 题：客观题 198（单选 180 + 判断 18）+ 开放作答 24 + 实操任务 24 + 对话任务 18 + 代码任务 18 + 图像鉴别 18，每维 50 题。

# AI 能力测评与成长平台 v1.6

面向 A01 赛题的可运行版本，已实现：

- 一套平台承载学生、教师、企业三类业务角色；学生端和教师端为重点，企业端保持轻量

- 六维 AI 能力模型与91题正式题库（基础90题每维15题，另含1道经项目成员确认的百宝箱生成开放题）
- 开放题和实操任务样例
- 按“维度 × 题型 × 难度”分层随机抽题，同场不重复
- 根据得分、题量、用时与置信度进行自适应补测
- 15～25 题测评与提前停止机制
- SQLite 用户、测评和答题记录，多用户会话互不干扰
- 客观题规则评分、开放题结构化评分、可选真实 LLM 接入
- 六维雷达图、证据记录、薄弱项建议与教师班级看板
- 六维 L1～L5 可观察行为标准及网页说明
- 题库管理、启停状态、版本记录与批量导入导出
- 百宝箱题库智能体生成待审草稿，教师确认后才写入正式题库
- 开放作答双人复核、争议裁决与一致性指标
- 学员成长档案、题目质量统计和研究数据CSV导出
- 预测试知情说明、中断续答、过程防泄题和测试反馈闭环
- 分阶段题号导航：阶段内自由选题，完成初测后解锁自适应题组
- 企业岗位能力模板、达到隐私阈值后的匿名群体概览，以及学生主动授权的可解释岗位参考
- 开放题/实操题过程引导与证据文件上传，文件采用类型、大小、SHA-256 和隔离路径校验

## 启动

需要 Python 3.10 或更高版本：

```powershell
python -m pip install -r backend/requirements.txt
python run.py
```

或双击 `一键启动.bat`。启动窗口会列出：

- `http://127.0.0.1:8000`：项目负责人在本机访问。
- `http://本机局域网IP:8000`：同一 Wi-Fi 或局域网内的队友访问。

队友测试期间必须保持启动窗口开启。如果队友无法访问，请确认双方在同一网络，并允许 Python 通过 Windows 防火墙的“专用网络”。不要把教学管理密钥发给普通测试者。

远程队友不在同一网络时：先运行 `一键启动.bat`，再运行 `启动远程测试.bat`，将窗口中生成的 `https://*.trycloudflare.com` 地址发给队友。该地址仅适合临时预测试，任一窗口关闭后即失效，并且下次启动通常会变化。

队内预测试建议选择 25 题模式。系统支持刷新后继续未完成测评；测试结束后，队友可以在报告页提交体验评分、歧义题、操作问题和报告反馈。

首次启动时会在 `data/admin_key.txt` 自动生成教学管理密钥。该文件仅供项目负责人本机查看，不要发送给普通测试者。也可以通过环境变量覆盖：

```powershell
$env:A01_ADMIN_KEY="自定义高强度密钥"
python run.py
```

企业端使用独立的 `data/enterprise_key.txt`，也可以通过环境变量覆盖。企业密钥不能代替教学管理密钥：

```powershell
$env:A01_ENTERPRISE_KEY="自定义高强度企业密钥"
python run.py
```

角色入口均在同一首页：学生从“会话”开测，教师进入“客观题/对话式/实操/报告”等管理流程，企业进入“企业协作”。企业端只能查看达到最小样本阈值的匿名聚合结果；个人岗位参考必须由学生本人明确授权，且不会进入企业群体接口。

## 百宝箱评分智能体

已发布的评分智能体 APP ID 为 `202608AP95fB21469777`。启动前在当前 PowerShell
会话中配置令牌和 APP ID；令牌只保存在进程环境变量中，不要写入代码、截图或题库：

```powershell
$env:TBOX_TOKEN="你的评分智能体令牌"
$env:TBOX_APP_ID="202608AP95fB21469777"
python run.py
```

系统会调用 `POST https://api.tbox.cn/api/chat`，校验百宝箱返回的结构化评分 JSON，
并把分数限制在题目满分范围内。远程调用异常时会显式标注警告并降级为
`rubric-fallback-v1`，不会把降级结果冒充为真实模型评分。

`GET /api/status` 中：

- `scoring_mode=baibaoxiang-agent` 表示百宝箱配置已加载；
- `baibaoxiang=configured` 表示令牌和 APP ID 均已配置；
- `scoring_mode=local-rubric` 表示当前仍是离线规则评分。

APP ID 已作为公开配置内置。为避免令牌落盘，可以在命令行使用隐藏输入启动：

```powershell
一键启动.bat --configure-tbox
```

令牌仅存在于本次启动进程；窗口关闭后失效。启动成功后必须再次查看 `/api/status`，确认 `baibaoxiang=configured`，并用一份开放题完成真实 `/api/chat` 冒烟验证。

## 百宝箱题库智能体（方案A）

评分智能体与题库智能体使用两套独立令牌和 APP ID。双智能体启动方式：

- 评分智能体 APP ID：`202608AP95fB21469777`
- 题库教研智能体 APP ID：`202608AP9YhY21462248`

```powershell
一键启动.bat --configure-tbox-both
```

终端会依次隐藏输入评分令牌、填写评分 APP ID、隐藏输入题库令牌、填写题库 APP ID；令牌只存在于当前进程，不会写入文件。启动后检查：

- `question_generation.configured=true`：题库智能体配置已加载；
- 教师端“题库管理 → AI生成草稿”：调用题库智能体生成一题；
- 生成结果只填入编辑表单，不会自动入库；
- 教师核对题干、唯一答案、解析和评分量表后，点击“教师确认并保存”才生成题目版本。

对应环境变量为 `TBOX_QUESTION_TOKEN` 与 `TBOX_QUESTION_APP_ID`。方案A坚持“AI生成—教师审核—正式入库”，避免模型输出未经检查就影响正式测评。

## 其他兼容大模型评分

未配置密钥时，开放题使用透明的 `rubric-fallback-v1` 规则评分，并标记需要人工复核。配置以下环境变量后会调用兼容 Responses API 的服务：

```powershell
$env:OPENAI_API_KEY="你的密钥"
$env:OPENAI_MODEL="模型名称"
python run.py
```

也可以通过 `OPENAI_BASE_URL` 指向兼容服务。密钥不会写入代码或数据库。

## 千题题库设计

系统不限制题库规模。每题使用统一字段：

```json
{
  "id": "PR1001",
  "dimension": "prompt",
  "difficulty": 2,
  "type": "single_choice",
  "tags": ["上下文", "少样本"],
  "question": "题干",
  "options": ["A", "B", "C", "D"],
  "answer": "A",
  "max_score": 10
}
```

扩展到千题时应由教师或领域专家审核题目质量、答案、难度和区分度，不建议用模板机械复制。抽题流程是：

1. 前 12 题按六维和基础/进阶难度配额分层随机；
2. 中段向低置信度或薄弱维度动态补题；
3. 末段加入开放题和实操任务；
4. 同一测评根据题目 ID 去重；
5. 达到目标题量，或满足提前停止条件后生成报告。

## 测评有效性模拟

```powershell
python -m algorithm.simulate_validation --runs 100 --target 18 --output docs/算法模拟报告.json
```

报告包含各能力档的平均得分、标准差、平均题目难度、预测等级分布和分类准确率。模拟用于发现算法问题，不能替代真实学员样本与人工评分验证。

当前正式题库共91题，五个维度各15题、结果评估维度16题，并通过结构与完整性校验。

### 100份分层仿真人工样本与模拟教师双评

```powershell
python tools/simulate_balanced_cohort.py --output-dir docs/synthetic_validation_100 --per-level 20 --target 25 --seed 20260816
```

该流程按 L1–L5 各20人生成100名仿真学员，每人具有独立专业背景、六维强弱项、速度、粗心率和开放题表达差异。流程生成2500条作答、200份非客观题答案、400条独立模拟教师评分，并对差异达到20%的答案进行模拟第三方裁决。结果仅用于算法、阈值和复核流程调试，不能替代真实学生试测或真实教师签字。

教师可通过 `GET /api/admin/validation/synthetic` 查看完整仿真校验报告；接口要求教学管理密钥。

## L1–L5等级阈值校准

系统使用100份仿真样本执行带监督断点搜索，同时强制五个区间宽度两两不同、五级人数两两不同。当前阈值为 `34.5 / 49.7 / 65.9 / 80.8`，对应人数为 `20 / 19 / 21 / 26 / 14`，模拟等级匹配率由旧阈值的31%提升到81%。统一配置位于 `config/level_thresholds.json`，正式评分、模拟器和能力标准页共用该配置。该结果属于仿真校准，不代表真人常模。
